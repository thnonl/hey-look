# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | yes |
| older than 1.0 | no |

## Reporting a vulnerability

Please report security problems **privately**. Do not open a public issue or a public pull request for a vulnerability.

- On GitHub: open the **Security** tab of this repository and choose **Report a vulnerability** (private vulnerability reporting).
- If you cannot use GitHub: write to namth.onl@gmail.com.

Please include the version (Settings > About), your system, what you did, what happened, and what you expected. Do not include real mail or passwords.

Hey Look! is a free, open source project. Reports are handled on a best-effort basis, without a fixed response time. You will be told when the problem is fixed, and credited in the release notes if you wish.
