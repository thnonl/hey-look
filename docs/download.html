First start on macOS: three steps, once

The app is self-signed but not notarised by Apple, so macOS blocks its first start.

  1. Open the .dmg, drag Hey Look! to Applications, and start it from Applications (not from the disk image).
  2. macOS says “Hey Look!” Not Opened. Click Done, not Move to Trash.
  3. Open System Settings > Privacy & Security, scroll to Security, click Open Anyway, confirm with your password or Touch ID, then click Open.

Prefer Terminal? Run this once instead of steps 2 and 3:

xattr -dr com.apple.quarantine "/Applications/Hey Look!.app"

Updates that Hey Look! installs itself start normally.

Install with APT and get updates with your system

For Ubuntu 22.04 or later and Debian 12 or later, on 64-bit PCs (amd64). Add the Hey Look! repository once: Hey Look! is then updated with the rest of your system, and the app no longer updates itself.

1. Download the signing key of the repository:

sudo wget -qO /etc/apt/keyrings/heylook-archive-keyring.gpg https://heylook.namthai.site/apt/heylook-archive-keyring.gpg

2. Add the repository:

sudo wget -qO /etc/apt/sources.list.d/heylook.sources https://heylook.namthai.site/apt/heylook.sources

3. Install Hey Look!:

sudo apt update && sudo apt install hey-look

The fingerprint of the signing key is 6A60 BC4B A845 ED1F C7DC 22A4 2718 BF04 5362 152C. To compare it with the key you downloaded, run:

gpg --show-keys /etc/apt/keyrings/heylook-archive-keyring.gpg

Already installed the .deb from this page? Follow the same three steps. Your mail, accounts and settings stay, and updates then come through APT.

To remove Hey Look! and the repository:

sudo apt remove hey-look && sudo rm /etc/apt/sources.list.d/heylook.sources /etc/apt/keyrings/heylook-archive-keyring.gpg
Notes for Linux

If your desktop has no tray area, closing the window quits Hey Look!

Links and attachments open with xdg-open. Passwords need GNOME Keyring or KWallet to be running and unlocked.

After you install

  1. Add a mailbox

    Sign in with Google or Microsoft, or add any account with IMAP/SMTP. iCloud and Yahoo need an app password.

  2. It updates itself

    Hey Look! looks for a new version on GitHub and installs it only after you agree. You can turn the check off.
