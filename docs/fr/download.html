Recommandé pour vous

Windows

Windows 10 et 11, 64 bits.

Télécharger le programme d’installation (.exe)HeyLook_<version>_windows_x64-setup.exe
Télécharger le MSIHeyLook_<version>_windows_x64.msi
Notes pour Windows

Les programmes d’installation ne sont pas encore signés numériquement. Si SmartScreen apparaît, choisissez Informations complémentaires, puis Exécuter quand même.

Le MSI est destiné aux installations gérées et n’installe pas WebView2 lui-même ; le setup.exe, si. Une mise à jour MSI demande des droits d’administrateur.

Recommandé pour vous

macOS

macOS 11 ou version ultérieure, Apple silicon et Intel (une seule version universelle).

Télécharger pour macOS (.dmg)HeyLook_<version>_darwin_universal.dmg
Premier lancement sous macOS : trois étapes, une seule fois

L’application est autosignée mais non notarisée par Apple ; macOS bloque donc son premier lancement.

  1. Ouvrez le .dmg, faites glisser Hey Look! vers Applications, puis lancez-le depuis Applications (pas depuis l’image disque).
  2. macOS affiche le message « Hey Look! n’a pas été ouvert ». Cliquez sur Terminé, et non sur Placer dans la corbeille.
  3. Ouvrez Réglages Système > Confidentialité et sécurité, faites défiler jusqu’à Sécurité, cliquez sur Ouvrir quand même, confirmez avec votre mot de passe ou Touch ID, puis cliquez sur Ouvrir.

Vous préférez le Terminal ? Exécutez ceci une fois à la place des étapes 2 et 3 :

xattr -dr com.apple.quarantine "/Applications/Hey Look!.app"

Les mises à jour que Hey Look! installe lui-même démarrent normalement. L’icône du Dock affiche le nombre de messages non lus (Paramètres > Notifications et zone de notification > Pastille du Dock). Les notifications ne sont pas disponibles sous macOS dans cette version.

Recommandé pour vous

Linux

Toute distribution avec l’AppImage, ou un paquet natif.

Télécharger AppImageHeyLook_<version>_linux_amd64.AppImage
Télécharger .deb (Debian, Ubuntu)HeyLook_<version>_linux_amd64.deb
Télécharger .rpm (Fedora, openSUSE)HeyLook_<version>_linux_x86_64.rpm
Notes pour Linux

Si votre bureau n’a pas de zone de notification, fermer la fenêtre quitte Hey Look!

Les liens et les pièces jointes s’ouvrent avec xdg-open. Les notifications nécessitent un service de notifications sur le bureau. Les mots de passe nécessitent que GNOME Keyring ou KWallet soit en cours d’exécution et déverrouillé.

Configuration requise

  • Windows 10 ou 11, 64 bits. Le runtime WebView2 est nécessaire : le setup.exe l’installe, le .msi non.
  • macOS 11 ou version ultérieure (Apple silicon et Intel).
  • Linux, x86_64.

Après l’installation

  1. Ajouter une boîte aux lettres

    Connectez-vous avec Google ou Microsoft, ou ajoutez n’importe quel compte avec IMAP/SMTP. iCloud et Yahoo nécessitent un mot de passe d’application.

  2. Elle se met à jour toute seule

    Hey Look! recherche sur GitHub une version plus récente, la télécharge après votre accord, vérifie la signature et redémarre après un compte à rebours de 5 secondes que vous pouvez annuler. Vous pouvez désactiver la vérification.

  3. Vos données restent les vôtres

    Le cache des messages est un fichier SQLite local sur votre ordinateur. Les secrets restent dans le trousseau de clés du système. Voir la politique de confidentialité.

Gmail

Connectez-vous avec votre compte Google. Hey Look! n’a pas encore terminé l’examen de Google ; Google affiche donc d’abord un avertissement (« Google n’a pas validé cette application ») et autorise jusqu’à 100 personnes à se connecter. Que faire. Avec un compte Gmail personnel, vous pouvez aussi utiliser un mot de passe d’application.
