ダウンロード

どうぞ。無料です。

すべての機能が、アカウントなし・広告なしで使えます。

GitHub Releasesから最新バージョンを入手してください。GitHub Releasesを開く
おすすめ

Windows

Windows 10 / 11（64ビット）。

インストーラー（.exe）をダウンロードHeyLook_<version>_windows_x64-setup.exe
MSIをダウンロードHeyLook_<version>_windows_x64.msi
Windowsについての注意

インストーラーはまだコード署名されていません。SmartScreenが表示されたら、詳細情報を選んでから実行を選んでください。

MSIは組織で管理するインストール向けで、WebView2自体はインストールしません（setup.exeはインストールします）。

Microsoft StoreMicrosoftから入手Hey Look!はMicrosoft Storeでも入手できます。インストールと最新の状態への更新は、Microsoft Storeが行います。
おすすめ

macOS

macOS 11以降、AppleシリコンとIntelに対応（ユニバーサルビルド1つ）。

macOS用（.dmg）をダウンロードHeyLook_<version>_darwin_universal.dmg
macOSでの初回起動：3つの手順（初回のみ）

このアプリは自己署名されていますがAppleによる公証を受けていないため、macOSは初回起動をブロックします。

  1. .dmgを開き、Hey Look!をアプリケーションにドラッグして、「アプリケーション」フォルダーから起動します（ディスクイメージからは起動しません）。
  2. macOSに「“Hey Look!”は開かれませんでした」と表示されます。完了をクリックします（「ゴミ箱に入れる」ではありません）。
  3. システム設定 > プライバシーとセキュリティを開き、セキュリティまでスクロールして、このまま開くをクリックします。パスワードまたはTouch IDで確認したら、開くをクリックします。

ターミナルを使う場合は、手順2と3の代わりに、次のコマンドを1回実行してください。

xattr -dr com.apple.quarantine "/Applications/Hey Look!.app"

Hey Look!自身がインストールするアップデートは、通常どおり起動します。

Linux

AppImageに対応するあらゆるディストリビューション、またはネイティブパッケージ。

AppImageをダウンロードHeyLook_<version>_linux_amd64.AppImage
.deb（Debian、Ubuntu）をダウンロードHeyLook_<version>_linux_amd64.deb
.rpm（Fedora、openSUSE）をダウンロードHeyLook_<version>_linux_x86_64.rpm
APTでインストール、更新はシステムで

Ubuntu 22.04以降とDebian 12以降の64ビットPC（amd64）向けです。Hey Look!のリポジトリを一度追加すると、Hey Look!はシステムの他のソフトウェアと一緒にアップデートされ、アプリ自身ではアップデートしなくなります。

1. リポジトリの署名鍵をダウンロードします：

sudo wget -qO /etc/apt/keyrings/heylook-archive-keyring.gpg https://heylook.namthai.site/apt/heylook-archive-keyring.gpg

2. リポジトリを追加します：

sudo wget -qO /etc/apt/sources.list.d/heylook.sources https://heylook.namthai.site/apt/heylook.sources

3. Hey Look!をインストールします：

sudo apt update && sudo apt install hey-look

署名鍵のフィンガープリントは6A60 BC4B A845 ED1F C7DC 22A4 2718 BF04 5362 152Cです。ダウンロードした鍵と照合するには、次のコマンドを実行してください。

gpg --show-keys /etc/apt/keyrings/heylook-archive-keyring.gpg

このページの.debをインストール済みですか？同じ3つの手順を行ってください。メール、アカウント、設定はそのまま残り、以後のアップデートはAPTで届きます。

Hey Look!とリポジトリを削除するには：

sudo apt remove hey-look && sudo rm /etc/apt/sources.list.d/heylook.sources /etc/apt/keyrings/heylook-archive-keyring.gpg
Linuxについての注意

デスクトップにトレイ領域がない場合、ウィンドウを閉じるとHey Look!が終了します。

リンクと添付ファイルはxdg-openで開きます。パスワードの保存には、GNOMEキーリングまたはKWalletが実行中でロック解除されている必要があります。

インストールしたあとに

  1. メールボックスを追加する

    GoogleまたはMicrosoftでサインインするか、IMAP/SMTPのアカウントを追加します。iCloudとYahooにはアプリパスワードが必要です。

  2. 自動でアップデートされます

    Hey Look!はGitHubで新しいバージョンを確認し、同意したあとにのみインストールします。この確認はオフにできます。
