ダウンロード

ダウンロード

どうぞ。無料です。

すべての機能が、アカウントなしで使えます。お使いのシステムを選んでください。Hey Look!は、同意したあとに自動でアップデートされます。

GitHub Releasesから最新バージョンを入手してください。GitHub Releasesを開く
おすすめ

Windows

Windows 10 / 11（64ビット）。

インストーラー（.exe）をダウンロードHeyLook_<version>_windows_x64-setup.exe
MSIをダウンロードHeyLook_<version>_windows_x64.msi
Windowsについての注意

インストーラーはまだコード署名されていません。SmartScreenが表示されたら、詳細情報を選んでから実行を選んでください。

MSIは組織で管理するインストール向けで、WebView2 自体はインストールしません（setup.exeはインストールします）。MSIのアップデートには管理者権限が必要です。

おすすめ

macOS

macOS 11 以降、AppleシリコンとIntelに対応（ユニバーサルビルド1つ）。

macOS用（.dmg）をダウンロードHeyLook_<version>_darwin_universal.dmg
macOSでの初回起動: 3つの手順（初回のみ）

このアプリはアドホック署名されていますがAppleによる公証を受けていないため、macOSは初回起動をブロックします。

  1. .dmgを開き、Hey Look!をアプリケーションにドラッグして、「アプリケーション」フォルダーから起動します（ディスクイメージからは起動しません）。
  2. macOSに「“Hey Look!”は開かれませんでした」と表示されます。完了をクリックします（「ゴミ箱に入れる」ではありません）。
  3. システム設定 > プライバシーとセキュリティを開き、セキュリティまでスクロールして、このまま開くをクリックします。パスワードまたはTouch IDで確認したら、開くをクリックします。

ターミナルを使う場合は、手順2と3の代わりに、次のコマンドを1回実行してください。

xattr -dr com.apple.quarantine "/Applications/Hey Look!.app"

Hey Look!自身がインストールするアップデートは、通常どおり起動します。Dockアイコンには未読数が表示されます（設定 > 通知とトレイ > Dockのバッジ）。このバージョンのmacOSでは、通知は利用できません。

おすすめ

Linux

AppImageに対応するあらゆるディストリビューション、またはネイティブパッケージ。

AppImageをダウンロードHeyLook_<version>_linux_amd64.AppImage
.deb（Debian、Ubuntu）をダウンロードHeyLook_<version>_linux_amd64.deb
.rpm（Fedora、openSUSE）をダウンロードHeyLook_<version>_linux_x86_64.rpm
Linuxについての注意

デスクトップにトレイ領域がない場合、ウィンドウを閉じるとHey Look!が終了します。

リンクと添付ファイルは xdg-open で開きます。通知には、デスクトップ側に通知サービスが必要です。パスワードの保存には、GNOMEキーリングまたはKWalletが実行中でロック解除されている必要があります。

システム要件

  • Windows 10 または 11（64ビット）。WebView2 ランタイムが必要です。setup.exeはこれをインストールしますが、.msiはインストールしません。
  • macOS 11 以降（AppleシリコンとIntel）。
  • Linux（x86_64）。

インストールしたあとに

  1. メールボックスを追加する

    GoogleまたはMicrosoftでサインインするか、IMAP/SMTPのアカウントを追加します。iCloudとYahooにはアプリパスワードが必要です。

  2. 自動でアップデートされます

    Hey Look!はGitHubで新しいバージョンを確認し、同意したあとにダウンロードして、署名を検証し、キャンセル可能な5秒のカウントダウンのあとに再起動します。この確認はオフにできます。

  3. データはあなたのものです

    メールのキャッシュは、お使いのコンピューター上のローカルのSQLiteファイルです。シークレットはシステムの資格情報ストアに保存されます。プライバシーポリシーをご覧ください。

Gmail

Googleアカウントでサインインします。Hey Look!はGoogleの審査をまだ完了していないため、最初にGoogleの警告（「このアプリはGoogleで確認されていません」）が表示され、サインインできるのは最大100人までです。対処法。個人のGmailアカウントなら、アプリパスワードも使えます。
