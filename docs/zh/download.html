为您推荐

Windows

Windows 10和11，64位。

下载安装程序（.exe）HeyLook_<version>_windows_x64-setup.exe
下载MSIHeyLook_<version>_windows_x64.msi
Windows使用须知

安装程序尚未经过代码签名。如果出现SmartScreen提示，请依次选择更多信息和仍要运行。

MSI适用于集中管理的部署，本身不会安装WebView2；setup.exe则会安装。

Microsoft Store从Microsoft获取Hey Look!也已上架Microsoft Store。由Microsoft Store负责安装并保持最新。
为您推荐

macOS

macOS 11或更高版本，支持Apple芯片和Intel（同一个通用版本）。

下载macOS版（.dmg）HeyLook_<version>_darwin_universal.dmg
在macOS上首次启动：三个步骤，只需一次

应用使用自签名证书签名，但没有经过Apple公证，所以macOS会阻止它的首次启动。

  1. 打开.dmg，把 Hey Look! 拖到应用程序，然后从“应用程序”中启动它（不要从磁盘映像中启动）。
  2. macOS会提示“Hey Look!”未打开。点击完成，不要点“移到废纸篓”。
  3. 打开系统设置 > 隐私与安全性，滚动到安全性，点击仍要打开，用密码或Touch ID确认，然后点击打开。

想用“终端”？可以只运行一次下面的命令，代替第2步和第3步：

xattr -dr com.apple.quarantine "/Applications/Hey Look!.app"

Hey Look!自行安装的更新可以正常启动。

Linux

任何发行版都可使用AppImage，也可使用原生安装包。

下载AppImageHeyLook_<version>_linux_amd64.AppImage
下载.deb（Debian、Ubuntu）HeyLook_<version>_linux_amd64.deb
下载.rpm（Fedora、openSUSE）HeyLook_<version>_linux_x86_64.rpm
通过APT安装，随系统一起更新

适用于Ubuntu 22.04或更高版本、Debian 12或更高版本的64位电脑（amd64）。只需添加一次Hey Look!软件源，Hey Look!就会和系统的其他软件一起更新，应用不再自行更新。

1. 下载软件源的签名密钥：

sudo wget -qO /etc/apt/keyrings/heylook-archive-keyring.gpg https://heylook.namthai.site/apt/heylook-archive-keyring.gpg

2. 添加软件源：

sudo wget -qO /etc/apt/sources.list.d/heylook.sources https://heylook.namthai.site/apt/heylook.sources

3. 安装Hey Look!：

sudo apt update && sudo apt install hey-look

签名密钥的指纹是6A60 BC4B A845 ED1F C7DC 22A4 2718 BF04 5362 152C。要将其与您下载的密钥比对，请运行：

gpg --show-keys /etc/apt/keyrings/heylook-archive-keyring.gpg

已经安装了本页的.deb？照样执行这三个步骤即可。您的邮件、账户和设置都会保留，此后更新将通过APT提供。

要删除Hey Look!和软件源，请运行：

sudo apt remove hey-look && sudo rm /etc/apt/sources.list.d/heylook.sources /etc/apt/keyrings/heylook-archive-keyring.gpg
Linux使用须知

如果您的桌面没有托盘区域，关闭窗口就会退出Hey Look!。

链接和附件通过 xdg-open 打开。密码保存需要GNOME Keyring或KWallet正在运行并已解锁。

安装之后

  1. 添加邮箱

    用Google或Microsoft登录，或添加任何支持IMAP/SMTP的账户。iCloud和Yahoo需要应用专用密码。

  2. 它会自行更新

    Hey Look!会到GitHub检查是否有新版本，只有经您同意才会安装。您可以关闭这项检查。

Gmail

在Google完成对Hey Look!的审核之前，Google会在登录时显示一条警告。该怎么办。
