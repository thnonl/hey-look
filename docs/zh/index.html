导览

九项你通常得花钱租用的功能。来试试看。

这个窗口是专为本页绘制的，里面是虚构的邮件。按钮和按键都能真正操作。向下滚动，场景就会切换。

  1. 01快速处理别处常需另外付费

    收件箱清零，快如打字。

    J 和 K 移动选择，E 归档，# 删除，S 延后，! 移至垃圾邮件。不用鼠标，不用菜单。归档、删除和移至垃圾邮件的操作要等3到30秒（默认6秒）后才会传到服务器，所以手滑了也只需点一下就能撤消。

    试一试。点一下窗口，然后按 J K E。也可以直接点按钮。

    应用中的实际快捷键：c、/、j、k、e、#、!、s、p、*、u、r、a、f。

  2. 02撤消发送别处常需另外付费

    点了发送，还有反悔的机会。

    邮件会在本地发件箱里等待0到60秒（默认10秒）。点了发送，发现错字，还来得及撤回。

    试一试。点发送，看倒计时。再选一个撤消时限。

    有一点要如实说明：暂存的邮件在程序崩溃后不会丢失，但正常退出时会立刻发出。

  3. 03定时发送别处常需另外付费

    现在写，稍后发送。

    选一个预设，或任意日期和时间，最长可安排到一年后。邮件由应用内部的后台任务发出，所以到时 Hey Look! 必须正在运行。

    试一试。点定时发送，选个时间。

    如果应用当时已关闭，邮件会在下次启动时发出（如果你设置为先询问，则会作为“已逾期”等待处理）。遇到临时错误最多重试3次。

  4. 04延后别处常需另外付费

    眼不见，等到该处理时再说。

    把一个对话延后到预设时间（1小时后、今天晚些时候、明天、周末、下周），或你自己设定的时间。到时它会回到收件箱。

    试一试。点延后，选个时间，再“快进”。

    在Windows和Linux上，邮件回来时会弹出通知；macOS上暂时还没有。

  5. 05命令栏别处常需另外付费

    按下Ctrl+K，想做什么都行。

    输入命令或文件夹名称：新建邮件、转到日历、切换邮箱、按发件人整理、主题、归档、标记、固定。大约有40条命令，几次按键就能到达。

    试一试。输入 深色、窗格 或 延后。方向键和Enter键都能用。

    macOS上用Cmd+K。在本页按Ctrl+K会跳到这里。

  6. 06加密别处常需另外付费

    加密它，签名它。

    内置OpenPGP。生成Ed25519或RSA 3072密钥并备份，发送前就能看到每位收件人是否有可用的密钥。

    试一试。先打开加密，再打开签名。

    私钥保存在应用的数据库中，由你的密码短语加锁，而不是放在操作系统的凭据存储里。尚未与其他OpenPGP软件做过互通测试。

  7. 07日历别处常需另外付费

    邀请来了，回复它。

    在邮件里的卡片上就能接受、暂定或拒绝。回复会从对应的邮箱发出，还可以附上一句话。提供月、周和日程视图。

    试一试。点一下接受。

    你可以同步Google或Microsoft邮箱的日历（可选，按邮箱分别设置）。在Google完成审核之前，Google登录和Google日历同步仅限前100位用户使用。CalDAV可能会在以后的更新中提供。

  8. 08远程图片别处常需另外付费

    订阅邮件没法偷偷向外报信。

    远程图片和背景图片在你加载之前一直被阻止，可以只对某封邮件加载一次，也可以对某个邮箱始终加载。跟踪像素说到底就是一张远程图片，所以和其他图片一起被阻止。

    试一试。点“加载内容”，再点“重新阻止”。

    你允许加载图片后，应用会尽量自己下载这些图片。对于无法代为下载的图片，邮件视图可能会直接去请求。

  9. 09隐私

    从这里到那里，全程就这一段路。

    中间没有 Hey Look! 服务器。邮件直接在应用和你的邮件服务商之间传输。密码和登录令牌保存在系统的凭据存储中。源代码里没有任何分析代码。

    试一试。看看这些信封，没有一封会“飞上云端”。

    应用其他的联网途径都列在示意图下方。“无分析代码”这一条是通过查看源代码确认的，而不是靠抓包。

    如实交代的清单
    
      
    哪些只做了一部分，哪些还没有。
    
      
    针对当前版本。与其让你日后才发现，不如在这里先说清楚。
    
    
    
    
    
      
    部分支持
      
        
    • 日历：事件、邀请、提醒和三种视图，可选择同步Google和Microsoft日历。在Google完成审核之前，Google登录和Google日历同步仅限前100位用户使用
    • 推送邮件：在支持IMAP IDLE的服务器上，收件箱的新邮件会立即送达；其他文件夹以及不支持IMAP IDLE的服务器，则按你设定的间隔检查（默认每2分钟一次）
    • 语言：默认为英语，在设置中可选择越南语、法语、简体中文、西班牙语、日语、德语和俄语。译文是新的，可能有错误
    • 外观：浅色、深色，7种颜色或自定义颜色，3种密度，2种窗格位置，6种文字大小。没有完整的主题编辑器
    • 更新：Windows上可完整自动更新；macOS和Linux需要你的许可
    • 源代码中没有分析代码（通过查看代码确认，而不是靠抓包）
    
      
    尚未提供
      
        
    • 没有移动端应用。仅限桌面。
    • 安装程序没有经过代码签名。首次启动时会出现SmartScreen或Gatekeeper的警告。
    • macOS版没有经过公证，也还没有原生通知；不过程序坞图标会显示未读数。
    • CalDAV和其他日历服务。日历同步目前只支持Google和Microsoft；CalDAV可能会在以后的更新中提供。
    • 搜索只涵盖已下载的邮件。不搜索服务器上的邮件。
    • 除这八种语言之外的更多语言，可能会在以后的更新中提供。
