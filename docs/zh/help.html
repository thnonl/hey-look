安装和首次启动

Windows：首次启动前会出现警告

安装程序没有使用发布者证书签名，所以 Windows 可能会显示 SmartScreen 警告。请依次选择更多信息和仍要运行。请使用 .exe。.msi 供公司统一安装软件使用。

macOS：首次不能打开应用

Apple 没有为这个应用做公证，所以第一次打开时 macOS 会阻止它。请按下载页面上的三个步骤操作一次；之后，应用和它的更新都能正常打开。

macOS：打印时询问本地网络

首次打印时，macOS可能会询问是否允许Hey Look!查找并连接到您本地网络上的设备。这样打印窗口才能找到您的打印机；Hey Look!不会将本地网络用于其他任何用途。

Linux：该用哪个文件，需要什么

AppImage 不用安装就能启动；.deb 适用于 Debian 和 Ubuntu，.rpm 适用于 Fedora 和 openSUSE。要保存密码，需要运行 GNOME Keyring 或 KWallet。

账户和邮箱

添加账户

用 Google 或 Microsoft 在它们自己的页面上登录，或者用邮箱地址和密码添加其他账户；Hey Look! 会自动找到设置。iCloud 和 Yahoo 需要应用专用密码，您可以在它们的账户页面上创建。部分 Microsoft 工作或学校账户需要管理员的许可。如果某项设置有误，“测试连接”会告诉您。

Google提示“Google未验证此应用”，或“使用Google登录”无法使用

Hey Look!尚未完成Google的审核。在 Google 完成对应用的审核之前，Google 都会显示这个警告；这并不表示您的账户有问题。

要继续，请选择高级，然后选择转至 Hey Look!（不安全），确认可以接受后再允许权限（请参阅Google API数据使用）。

如果Google登录无法使用，请改用应用专用密码添加个人Gmail账户，作为其他邮箱账户，服务商选 Gmail。

新邮件会立即送达吗？

会。只要您的邮件服务器支持，并且 Hey Look! 正在运行，收件箱以及“收藏夹”中最多三个文件夹的新邮件会立即收到。其他文件夹会定期检查；检查的频率可以在“设置 > 邮箱 > 阅读与同步”中设置。

日常使用

键盘快捷键

Ctrl K（macOS上为 Cmd K）打开命令栏。在邮件列表中：c 新建邮件，/ 搜索，j 和 k 移动，e 归档，# 删除，s 稍后提醒，r 回复。

撤销发送和定时发送

按下“发送”后，邮件会等几秒，让您可以撤销；等待多久可以在设置中更改。定时发送要求 Hey Look! 在您选定的时间正在运行；如果那时应用已关闭，邮件会在您下次打开应用时发出。

更新

从本网站安装的版本会自己检查更新，只有在您同意后才会安装。您可以在“设置 > 关于”中关闭这项检查。在 Windows 上，.msi 会要求管理员权限；在 Linux 上，.deb 和 .rpm 会要求输入您的密码。

Hey Look! 也已上架 Microsoft Store，Store 版本的更新由 Store 安装。

Store 版本使用自己的邮件、账户和设置。同一台电脑上，请只使用 Store 版本或本网站的版本，不要两个都装。

更改语言

在“设置 > 常规”中选择。默认语言是英语；Hey Look! 不会跟随系统的语言。

隐私与数据存放位置

我的数据存放在哪里？

邮件和设置保存在一个本地文件夹中：Windows上为%APPDATA%\thnonl.heylook，macOS上为~/Library/Application Support/thnonl.heylook，Linux上为~/.local/share/thnonl.heylook。密码和登录令牌保存在系统的密码存储中；OpenPGP私钥保存在应用的数据库中，由您的密码短语加锁。

哪些内容会离开我的电脑？

只有您用到的部分：您的邮件服务器；登录或同步日历时的 Google 或 Microsoft；您设置的日历服务器；添加账户时对设置的查询；用于更新的 GitHub；您设置的 AI 服务；托管已显示图片的服务器；以及您取消订阅时打开的取消订阅页面。应用不做任何分析统计。隐私政策列出了每一个连接。

卸载，并清除所有内容

在设置中移除您的账户（邮件仍留在服务器上），卸载应用，然后删除它的数据文件夹，并从系统的密码存储中删除已保存的 Hey Look! 密码。

OpenPGP基础

创建密钥、加密、签名

在设置中创建密钥，用密码短语保护它，并保存它提供的备份。写邮件时，打开“加密”或“数字签名”；Hey Look! 会显示您可以给哪些收件人加密。

报告问题

错误或功能建议

请在GitHub上提交一个议题，并说明您使用的系统和Hey Look!版本（在设置的“关于”中可以看到）。议题是公开的，所以千万不要贴出私人邮件、密码或令牌。

安全问题

请私下报告：打开github.com/thnonl/hey-look/security并选择“Report a vulnerability”（报告漏洞），或发邮件到namth.onl@gmail.com。请不要公开提交议题。详见安全。

AI助手生成的内容

AI助手会把您的请求发送到您在“设置 > AI助手”中设置的AI服务，由该服务生成回答。Hey Look!不提供也不控制AI模型，AI撰写的文字可能有误。

如果AI助手显示了有害、冒犯性或违法的内容，请告诉我们：在GitHub上提交issue，或发邮件到namth.onl@gmail.com。请注明AI服务和模型，切勿附上私人邮件或您的API密钥。也请向您的AI服务提供方举报。
