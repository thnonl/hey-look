Hey Look! 对从Google API获得的信息的使用，将遵守Google API Services User Data Policy（Google API服务用户数据政策），包括其中的Limited Use（有限使用）要求。这也包括通过Google日历API获得的日历信息。Hey Look! 同时遵守Google Workspace API User Data and Developer Policy（Google Workspace API用户数据和开发者政策）。

Hey Look! 是什么

一款免费、开源的桌面电子邮件客户端：你可以在电脑上的应用窗口中阅读、撰写、发送、搜索和整理你的Gmail。

如果你为某个Google账户开启日历同步，Hey Look! 还会在自己的日历中显示你的Google日历里的事件，并把你在其中创建、修改、删除或回复的事件同步保存回Google日历。这是可选的，按邮箱分别设置，在你开启之前默认关闭。

请求的权限

请求的权限原因应用如何使用它
https://mail.google.com/（阅读、撰写、发送和永久删除你Gmail中的所有电子邮件）唯一适用于IMAP和SMTP的Google权限；IMAP和SMTP是 Hey Look! 对所有服务商都使用的标准邮件协议把你的邮件下载到你的电脑上，发送你撰写的邮件，执行你的操作（已读或未读、标记、移动、归档、垃圾邮件、删除；只有当你从“已删除邮件”中删除时，才会永久删除）
https://www.googleapis.com/auth/calendar.events（查看和编辑你所有日历上的事件）用于在应用中显示你的Google日历里的事件，并把你创建、修改、删除或回复的事件保存回Google日历。只有在你开启与Google同步日历时才会请求，且是与邮件分开的单独权限把你所选日历的事件（从一年前起）下载到你的电脑上，并把你在 Hey Look! 中添加、修改、删除或回复的事件发送到Google日历。绝不会更改日历的设置或共享方式
https://www.googleapis.com/auth/calendar.calendarlist.readonly（查看你订阅的日历列表）用于列出你的日历及其名称和颜色，以便你选择要同步哪些只读取该列表；绝不更改它
openid、email、profile用于知道你是用哪个Google账户登录的显示该账户的电子邮件地址和名称

Hey Look! 绝不会对Google数据做什么

  • 它绝不会被发送到 Hey Look! 的服务器（根本没有这样的服务器）。
  • 它绝不会被出售或用于广告。
  • 参与 Hey Look! 的任何人都不会阅读它。
  • 我们不会用它来创建、训练或改进AI或机器学习模型。
  • 它不会被转让给任何人，除非你使用可选的AI助手：这时，你所选邮件或草稿的文字会发送到你配置的AI端点，以生成你所要求的总结、翻译或草稿。
  • 日历数据与邮件同等对待：不用于广告，不会被参与 Hey Look! 的任何人阅读，不用于训练AI模型，并且绝不会发送给AI助手（AI按钮只作用于邮件）。

数据存放在哪里

仅存放在你的电脑上：邮件在本地数据库中，登录令牌在你系统的凭据存储中。开启了日历同步的邮箱的日历和事件同样存放在本地数据库中；日历登录令牌则作为单独的一个条目保存在你系统的凭据存储中（<account id>:calendar）。

如何停止访问

在 Hey Look! 中移除该账户（设置 > 邮箱 > 账户 > 移除账户），并在myaccount.google.com/permissions撤销对 Hey Look! 的授权。

如果只想停用日历：关闭设置 > 邮箱 >（账户）> 日历 > 与Google同步日历。日历和事件会从这台电脑上移除，日历令牌也会被删除；它们仍保留在Google日历中。如需在Google撤销日历权限，请使用同一个页面：myaccount.google.com/permissions。

用你的Google账户快速登录Gmail。
