Установка и первый запуск

Windows предупреждает перед первым запуском

Установщики пока не подписаны цифровой подписью кода. Если появится SmartScreen, выберите Подробнее, затем Выполнить в любом случае. Используйте .exe; .msi предназначен для управляемых установок.

macOS не открывает приложение в первый раз

Приложение не нотаризовано Apple, поэтому macOS один раз блокирует его первый запуск. Выполните три шага со страницы загрузки; после этого обновления запускаются как обычно.

Linux: какой файл и что нужно

AppImage работает в любом дистрибутиве; .deb — для Debian и Ubuntu, .rpm — для Fedora и openSUSE. Для паролей должны быть запущены и разблокированы GNOME Keyring или KWallet, а ссылки открываются через xdg-open.

Учётные записи и почтовые ящики

Добавление учётной записи

Войдите через Google или Microsoft на странице самого провайдера либо добавьте любую другую учётную запись по IMAP и SMTP: Hey Look! находит серверы по вашему адресу. Для iCloud и Yahoo нужен пароль приложения со страницы вашей учётной записи. Некоторым рабочим и учебным учётным записям Microsoft нужно, чтобы администратор разрешил IMAP и SMTP.

Google сообщает: «Google hasn’t verified this app»

Hey Look! ещё не прошёл проверку Google. Google показывает это предупреждение для каждого приложения, которое проходит проверку; с вашей учётной записью всё в порядке.

Чтобы продолжить, выберите Advanced («Дополнительные настройки»), затем Go to Hey Look! (unsafe) («Перейти на страницу Hey Look! (небезопасно)»), и подтвердите разрешения, если вас всё устраивает (см. Использование данных Google API).

Пока проверка не завершена, Google разрешает войти через Google только первым 100 людям, и для почты, и для синхронизации календаря. Если вход перестал работать, добавьте личный Gmail с паролем приложения как учётную запись IMAP с провайдером Gmail.

Приходит ли новая почта сразу?

Да, для папки «Входящие», на серверах с поддержкой push (IMAP IDLE), пока Hey Look! запущен. Остальные папки и серверы без push проверяются по умолчанию каждые 2 минуты.

Повседневное использование

Клавиатурные сочетания

Ctrl K (Cmd K в macOS) открывает палитру команд. В списке писем: c — новое письмо, / — поиск, j и k — перемещение, e — архивировать, # — удалить, s — отложить, r — ответить.

Отмена отправки и «Отправить позже»

После «Отправить» письмо по умолчанию ждёт 10 секунд (до 60), чтобы вы могли отменить отправку; обычный выход отправляет его сразу. Для «Отправить позже» Hey Look! должен быть запущен в нужное время; письмо, время которого прошло, пока приложение было закрыто, по умолчанию уходит при следующем запуске.

Обновления

Hey Look! проверяет GitHub при запуске и, не чаще чем раз в 2 часа, когда его окно возвращается; после неудачной проверки он повторяет её через 15 минут. Это можно отключить в разделе «Настройки». Ничего не скачивается, пока вы не согласитесь, и устанавливается только обновление с правильной подписью. Установщик .msi запрашивает права администратора, .deb и .rpm — ваш пароль.

Смена языка

Выберите язык в разделе «Настройки > Общие». По умолчанию используется английский; Hey Look! не выбирает язык по настройкам вашей системы.

Конфиденциальность и где хранятся ваши данные

Где мои данные?

Почта и настройки находятся в одной локальной папке: %APPDATA%\thnonl.heylook в Windows, ~/Library/Application Support/thnonl.heylook в macOS, ~/.local/share/thnonl.heylook в Linux. Пароли и токены хранятся в системном хранилище учётных данных; секретные ключи OpenPGP — в базе данных приложения, под защитой вашей парольной фразы.

Что покидает мой компьютер?

Только то, чем вы пользуетесь: ваши почтовые серверы, вход и календарь Google или Microsoft, поиск настроек сервера при добавлении учётной записи, GitHub для обновлений, ваша конечная точка ИИ, разрешённые вами изображения и запросы на отписку. Кода аналитики нет. Все соединения перечислены в политике конфиденциальности.

Удаление приложения и всех данных

Удалите свои учётные записи в разделе «Настройки» (почта остаётся на сервере), удалите приложение, затем удалите его папку данных и записи, имена которых начинаются с heylook, в системном хранилище учётных данных.

Основы OpenPGP

Создать ключ, зашифровать, подписать

Создайте ключ в разделе «Настройки», защитите его парольной фразой и сохраните предлагаемую резервную копию. При написании письма включите «Шифровать» или «Подписать»; Hey Look! показывает, есть ли у каждого получателя ключ. Совместимость с другим ПО для OpenPGP пока не проверялась.

Сообщить о проблеме

Ошибка или идея новой возможности

Откройте issue на GitHub и укажите, какой системой и какой версией Hey Look! вы пользуетесь (она показана в разделе «Настройки > О программе»). Issues видны всем, поэтому никогда не публикуйте личную почту, пароли или токены.

Проблема безопасности

Сообщите о ней приватно: откройте github.com/thnonl/hey-look/security и выберите “Report a vulnerability” («Сообщить об уязвимости») или напишите на namth.onl@gmail.com. Пожалуйста, не создавайте публичный issue. См. Безопасность.

Известные ограничения

Чего Hey Look! пока не умеет

Установщики не подписаны цифровой подписью кода, вход через Google пока ограничен 100 людьми, поиск работает только по загруженной почте, а синхронизация календаря охватывает только Google и Microsoft. Полный список — на странице «Возможности».

Подходящих вопросов нет. Попробуйте одно слово или спросите на GitHub.
