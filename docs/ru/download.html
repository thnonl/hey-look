Первый запуск в macOS: три шага, один раз

Приложение подписано самоподписанным сертификатом, но не нотаризовано компанией Apple, поэтому macOS блокирует его первый запуск.

  1. Откройте .dmg, перетащите Hey Look! в Программы и запустите приложение из папки «Программы» (а не из образа диска).
  2. macOS сообщает: «Hey Look!» не открыто. Нажмите Готово, а не «Переместить в Корзину».
  3. Откройте Системные настройки > Конфиденциальность и безопасность, прокрутите до раздела Безопасность, нажмите Всё равно открыть, подтвердите паролем или Touch ID и нажмите Открыть.

Предпочитаете Терминал? Выполните это один раз вместо шагов 2 и 3:

xattr -dr com.apple.quarantine "/Applications/Hey Look!.app"

Обновления, которые Hey Look! устанавливает сам, запускаются как обычно.

Установка через APT: обновления с системой

Для Ubuntu 22.04 и новее и Debian 12 и новее, на 64-разрядных ПК (amd64). Добавьте репозиторий Hey Look! один раз: после этого Hey Look! будет обновляться вместе с остальной системой, а само приложение перестанет обновляться самостоятельно.

1. Скачайте ключ подписи репозитория:

sudo wget -qO /etc/apt/keyrings/heylook-archive-keyring.gpg https://heylook.namthai.site/apt/heylook-archive-keyring.gpg

2. Добавьте репозиторий:

sudo wget -qO /etc/apt/sources.list.d/heylook.sources https://heylook.namthai.site/apt/heylook.sources

3. Установите приложение:

sudo apt update && sudo apt install hey-look

Отпечаток ключа подписи: 6A60 BC4B A845 ED1F C7DC 22A4 2718 BF04 5362 152C. Чтобы сверить его со скачанным ключом, выполните:

gpg --show-keys /etc/apt/keyrings/heylook-archive-keyring.gpg

Уже установили .deb с этой страницы? Выполните те же три шага. Ваша почта, учётные записи и настройки сохранятся, а обновления будут приходить через APT.

Чтобы удалить Hey Look! и репозиторий:

sudo apt remove hey-look && sudo rm /etc/apt/sources.list.d/heylook.sources /etc/apt/keyrings/heylook-archive-keyring.gpg
Заметки для Linux

Если на вашем рабочем столе нет системного трея, закрытие окна завершает Hey Look!

Ссылки и вложения открываются через xdg-open. Для паролей должны быть запущены и разблокированы GNOME Keyring или KWallet.

После установки

  1. Добавьте почтовый ящик

    Войдите через Google или Microsoft либо добавьте любую учётную запись с IMAP/SMTP. Для iCloud и Yahoo нужен пароль приложения.

  2. Он обновляется сам

    Hey Look! проверяет на GitHub наличие новой версии и устанавливает её только после вашего согласия. Проверку можно отключить.
